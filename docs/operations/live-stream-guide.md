# 企业采购竖屏直播页

直播入口：`/live/`。默认显示企业服务主题，手动切换，不自动滚动。

## 画面内容

- 固定定位：专门服务企业；ChatGPT Pro 5x / 20x 集中采购。
- 企业服务：采购越多，单价越低；对公付款、6% 专票、盖章合同、专属售后。
- 采购支持：需求选型、阶梯报价、立项材料、合同对接。
- 售后保障：专属经理、异常响应、续期提醒、协议保障。退换以服务协议约定为准。
- 固定咨询指引：私信「企业采购」，对接专属经理获取采购方案。需要在实际直播平台接收和处理私信，网页本身不接收私信。

## 开播

1. 打开直播工作台，选择讲解主题。
2. 展开「平台遮挡预留」，对照直播平台的顶部信息、右侧互动按钮和底部评论调整预留比例。可开启参考线辅助对齐。
3. 点击「进入纯净画面」或「全屏录制」。控制台和参考线自动隐藏。
4. 推流画布设为 **1080 × 1920（9:16）**。桌面录屏只捕获中间的竖屏画布；横屏显示器两侧黑边不要录入。显示器全屏不会改变画布比例。
5. 也可点击「复制画面链接」，用作直播软件的浏览器源，宽 1080、高 1920。链接包含复制时的主题、轮播与预留区设置。浏览器源是独立页面，之后在工作台修改设置需要重新复制链接。

首次加载后，确认画面和字体均已显示再开始录制。用手机检查推流后的清晰度和平台浮层遮挡。

## 操作

| 操作 | 快捷方式 |
| --- | --- |
| 企业服务 / 采购支持 / 售后保障 | `1` / `2` / `3` |
| 前一个 / 下一个主题 | 左 / 右方向键 |
| 开启 / 暂停轮播 | 空格（焦点不在表单或按钮上时） |
| 隐藏 / 显示控制台 | `H` |
| 返回控制台 | `Esc` 或双击纯净画面 |

轮播每 30 秒切换一次，手动选择主题会暂停轮播。快捷键需要录制页面获得键盘焦点。

## 纯净画面地址

默认：`/live/?clean=1`。

可选参数：`scene=enterprise|procurement|support`、`autoplay=1`、`top=8`、`bottom=20`、`right=10`。预留比例单位为百分比，并限制在控制台允许的范围内。建议直接使用工作台生成的链接。
